# MongoDB Student Management Project

## Project Description
This project is a Student Management System developed using MongoDB. It demonstrates how student records can be stored, managed, searched, updated, and deleted using MongoDB operations.

## Objectives
- Store student information in a MongoDB database.
- Perform CRUD operations on student records.
- Search and retrieve student information.
- Update existing student records.
- Delete student records when required.
- Understand basic MongoDB database operations.

## Technologies Used
- MongoDB
- MongoDB Compass / MongoDB Shell
- JavaScript

## Database Details
The project contains student information such as:
- Student ID
- Student Name
- Roll Number
- Marks
- Address
- Father's Name

## Operations Performed
The project demonstrates:
- Create / Insert
- Read / Find
- Update
- Delete
- Search and filtering of student records

This project provides practical understanding of MongoDB and demonstrates how a student database can be created and managed using basic database operations.
